2テキスト生成AI

自然言語処理と機械学習の技術を利用して、文章やテキストデータを自動的に生成する技術。

仕組みと用語

NLP（Natural Language Processing／自然言語処理）

コンピュータに人間の言葉を理解させるための技術。生成AI専用の技術ではなく、 翻訳ソフトによる日本語訳や、スマートスピーカーが人の話を理解して答える処理にも同じくNLPが使われている。

LLM（Large Language Model／大規模言語モデル）

非常に大規模なデータセットで学習された自然言語処理モデルのこと。 テキスト生成AIの中身はこのLLMで、もっともよく知られている代表例が OpenAI の ChatGPT。

主なサービスと提供元

「サービス名 ↔ 提供している会社」の組み合わせはそのまま出題される。ここは丸暗記でよい。

サービス提供元特徴
ChatGPTOpenAI テキスト生成AIの代表例。2022年11月公表。詳細は 9章・10章。
ClaudeAnthropic OpenAI の有力な競合。あらかじめ定めた原則に沿って「無害・役立つ・正直」を保つ Constitutional AI を採用。 2024年3月の Claude 3 から Haiku（超高速・低コスト）／Sonnet（バランス）／Opus（最上位・複雑な推論）の三種類構成。 文書やコードを別ウィンドウで並行生成・編集できる Artifacts 機能を持つ。
GeminiGoogle
（Google DeepMind）		 2023年12月の初代から 1.5 → 2.0 → 2.5 と進化。最初からテキスト・画像・音声・動画・コードを同じモデルで扱うよう学習された ネイティブなマルチモーダル設計が特徴。2.5 Pro は超長コンテキスト（最大104万トークン）、2.5 Flash は速度とコスト効率重視、Nano は端末上で動く軽量版。

試験ポイント

  • ChatGPT＝OpenAI ／ Claude＝Anthropic ／ Gemini＝Google。この3つの入れ替えが定番の誤答肢。
  • NLP の正式名称は Natural Language Processing（Neural… ではない）。
  • LLM の説明は「大規模なデータセットで学習された自然言語処理モデル」。「小規模で特化した」は誤り。

テキスト生成AIが不得意なこと

シラバス第5章の項目だが、テキスト生成AIの性質としてセットで覚えると効く。 ①正確な文字数の指定 ②計算 ③最新の情報 ④芸術の批評。 「文字数はきっちり守れる」「計算が得意」という肢は誤り。

3画像生成AI

コンピュータが画像を生成するための技術。手法の変遷（GAN・VAE → 拡散モデル）が最頻出。

学習の流れと前処理

  1. インターネット上にある大量の画像データを収集し、学習に使用する。
  2. 収集した画像は前処理をして、モデルに適した形式に変換する。

前処理の3手法（そのまま出る）

画像のリサイズ ／ 正規化 ／ データの水増し

リサイズ＝サイズを揃える。正規化＝画素値のスケールを揃える。データの水増し（データ拡張）＝反転・回転などで学習データの量と多様性を増やす。

3つの手法

手法正式名称仕組み
① GAN 敵対的生成ネットワーク
Generative Adversarial Network		 生成器（ジェネレータ）と識別器（ディスクリミネータ）を競わせることで、高品質な画像を生成する。 生成器は「本物らしい偽物」を作ろうとし、識別器は「本物か偽物か」を見分けようとする。
② VAE 変分自己符号化器
Variational Auto-Encoder		 エンコーダとデコーダからなる。
・エンコーダ＝情報を圧縮し、潜在ベクトル（特徴を要約した情報）にする
・デコーダ＝潜在ベクトルから元のデータに近いものを復元する
③ CNN 畳み込みニューラルネットワーク
Convolutional Neural Network		 画像認識・画像処理に強いモデル。画像の局所的な特徴から、全体的な特徴を抽出できる。

現在の主流：ディフュージョン（拡散）モデル

GAN と VAE 中心から移行し、現在はディフュージョン（拡散）モデルが主流。 ノイズを段階的に「除去」していくことで、学習の安定と超高精細を両立する。

補足：拡散モデルは学習の段階では「元画像にノイズを加えていく過程」を学ぶが、 画像を作る（生成する）ときはその逆で、ノイズだらけの状態から段階的にノイズを取り除いていく。 試験で問われるのは「ノイズを段階的に除去して画像を完成させる」側なので、こちらを答えにする。

自己回帰型 Transformer の組み合わせ

拡散モデルに加えて、自己回帰型 Transformer（自己回帰モデル）を組み合わせる方式が登場した。 画像をトークン化して順次生成することで、 看板の文字や細線などの細部も破綻なく表現できるようになった。

OpenAI の Image Generation（2023年10月発表）がこの方式で、左上から右下へ順に描いていく。 従来の DALL·E や Stable Diffusion が使う拡散モデルとは別方式である点が対比で問われる。→ 10章の年表

試験ポイント

  • 「現在は GAN と VAE が主流」は誤り。拡散モデルが主流。
  • 「拡散モデルはノイズを段階的に加えていく」は誤り。生成の説明としては除去。
  • VAE のエンコーダ＝圧縮して潜在ベクトルへ／デコーダ＝復元。役割を入れ替えた肢が定番。
  • 前処理3つ（リサイズ・正規化・水増し）に「ノイズ除去」「トークン化」などを混ぜた肢は誤り。

4音楽生成AI

コンピュータが音楽を作り出すための技術。MIDI・RNN・リスナーのフィードバックの3語が軸。

学習と生成のサイクル

  1. AI は既存の音楽データセットから学習する。データセットには MIDIファイル（デジタル音楽のインターフェース規格）等の音楽データが含まれる。
  2. シーケンス（連続した）データの処理に長けている RNN 等を用いて、データセットの情報を水増しする。
  3. それをもとに音楽を生成し、人間のリスナーからのフィードバックを受ける。
  4. そのフィードバックを新たな学習データとしてデータセットに追加することで、 より好まれる音楽を生成する能力を獲得していく。

RNN（Recurrent Neural Network／回帰型ニューラルネットワーク）＝過去の情報を記憶しながら新しい入力を処理する特性があり、 音楽・音声・動画のような「順番に意味がある」連続データの扱いに向く。音楽生成AIと動画生成AIの両方で登場する。

試験ポイント

  • 学習データの代表として MIDIファイル が挙がる。「MP3のみ」「楽譜画像のみ」は誤り。
  • 水増しに使うのは RNN 等（シーケンスデータに強い）。CNN や GAN と入れ替えた肢に注意。
  • 好まれる音楽を作れるようになる仕組みはリスナーのフィードバックをデータセットに追加していくこと。

デメリット側でも問われる

生成AIのデメリットの1つ「その業界の職業への影響」の例として、音楽生成AIが挙げられている。 「音楽家に対する需要が減少する可能性がある」が正しい向き。「需要が増加するとされている」は誤り。

参考（試験範囲外）：実サービスとしては Suno、Udio、Google の MusicLM などがある。書籍・シラバスでは音楽生成AIの具体的サービス名は指定されていないので、覚える必要はない。

5音声生成AI

コンピュータが音声を生成するための技術。「教師あり学習」と TTS が最重要ワード。

学習のしかた

大量の音声データを使用して、ディープラーニングモデルをトレーニングする。 このトレーニングには、一般的に 教師あり学習 が用いられる。

※ここが定番のひっかけどころ。「強化学習が用いられる」「教師なし学習のみ」は誤り。

主な技術・サービス

名称内容
TTS
Text-to-Speech		 テキストを自然な音声へ変換する技術。 多言語・多話者・感情表現に対応し、読み上げやナレーションに利用される。OpenAI も TTS を提供している。
Eleven Labs 少量のサンプルから声色を再現できる高品質な TTS。 感情や話速の制御、多言語合成に対応し、制作現場で広く利用されている。
リップシンク 特定の人物画像の口の動きを音声に合わせて動かす技術。近年進化し、よりリアルで自然な表現が可能になった。 エンターテインメントからビジネスまで活用が広がっている。

試験ポイント

  • トレーニングは一般に 教師あり学習。
  • TTS ＝ Text-to-Speech（テキスト→音声）。逆向きの「音声→テキスト」は STT／音声認識で別物。
  • 「音声生成AIは感情表現に対応できない」は誤り。TTS も Eleven Labs も感情表現・感情制御に対応する。
  • 音楽生成AI（音楽を作る）と音声生成AI（人の声を作る）を混同しない。

6動画生成AI

コンピュータが静止画像を連続的に結合して動画を生成する技術。フレーム間の一貫性が鍵。

仕組み

  1. 大量の動画データを収集する。
  2. AI が処理しやすいようにフレームごとに分割し、前処理する。
  3. 主な訓練手法には GAN や VAE がある。
  4. 各フレーム間の一貫性を保つことが重要で、連続性データの処理に適する RNN が利用される。

代表的なモデル

モデル提供元 / 発表内容
Sora OpenAI
2024年2月		 文章や画像を入力すると動画を生成する。発表時は最長1分間の動画を生成できる可能性のあるモデルとして大きな注目を集めたが、 製品版では最長20秒・最大1080p（フルHD）。教材づくりや広告の試作、研修シミュレーション素材などに活用されている。
Veo 3 Google DeepMind
2025年5月		 超高精細映像を生成し、さらに環境音やセリフ等の音声も同時に合成できるのが特徴。

試験ポイント

  • フレーム間の一貫性を保つのは RNN。訓練手法は GAN・VAE。役割を混ぜた肢に注意。
  • Sora＝2024年2月・OpenAI・最長20秒/1080p。「1分」は発表当時の注目点で、製品版は20秒。
  • Veo 3＝Google DeepMind・2025年5月・音声も同時合成。Sora と提供元を入れ替えた肢が出る。
  • デメリット側では「AI生成動画は映像の連続性や音と映像の同期の点で人間の手作業に品質が劣る可能性」が正しい向き。 「常に高品質」は誤り。

関連：ディープフェイク（深層偽造）

ディープラーニングや生成AIを利用して非常にリアルなコンテンツを作り、 人を故意に騙すことを目的として使用される技術。映像内の人物の顔を別人に差し替えたり、既存の映像に表情や動きを追加したりできる。 鑑識能力を超えるほど高品質なフェイク映像が作られることもあり、 偽情報（ディスインフォメーション）の拡散という社会的問題を引き起こしている。

8メリットとデメリット

5分類とセットで出題される。「〜が自動的に保証される／不要になる」と書いてある肢は、ほぼ誤りと考えてよい。

メリット（5つ）

  1. 作業効率の向上 — 短時間で多くのコンテンツを生成でき、作成やタスクの自動化が進む。
  2. 補完と拡張が可能 — 与えられたデータの内容を理解し、関連情報を補完・拡張できる。不足部分を補うこともできる。
  3. 新たなアイデア・デザインの生成 — 既存コンテンツから情報収集・分析を行い、新しい案を生み出せる。
  4. アクセシビリティの向上 — 専門知識がなくても、音楽・画像・動画の制作やプログラミングコードの作成・修正ができる。
  5. 言語の壁の克服 — 異なる言語間での文章・音声のやり取りが可能になる。

デメリット（6つ）

  1. 虚偽の情報や不適切なコンテンツの生成 — 信頼性や正確性は人間がチェックする必要がある。
  2. 偏見・差別的なコンテンツの生成 — 学習データに偏りがある場合に起こる。倫理面への留意が必要。
  3. プライバシー侵害等 — データ入力時に個人情報や機微（センシティブ）情報を含めない配慮が必要。
  4. 著作権等の知的財産権侵害 — 著作権・特許権・商標権・意匠権を侵害する可能性があり、権利関係のチェックが必要。
  5. その業界の職業への影響 — 例：音楽生成AIの活用により、人間の音楽家への需要が減少する可能性。
  6. 質の低下 — 例：AI生成動画は、映像の連続性や音と映像の同期の点で、人間の手作業の制作物に品質が劣る可能性。

誤答肢の見分け方

  • 「生成物の正確性が自動的に担保されるため、人間による確認が不要」→ 誤り
  • 「生成物の著作権が自動的に利用者に帰属するため、権利処理は不要」→ 誤り
  • 「学習データが偏っていても、AI が中立に補正する」→ 誤り

9ChatGPTとは

OpenAI が開発した一連の自然言語処理モデル。2022年11月に公表された。

名前の意味

Chat対話型
GGenerative（生成）
PPre-trained（事前学習）
TTransformer（Transformerモデル）

チャットのやり取りが機械的ではなく、人間と会話しているようにごく自然に展開されるのが特徴。

ここを間違えない

  • ChatGPT は公表される数年前から複数のバージョンが存在する。「公表と同時に開発が始まった」は誤り。
  • 2022年11月にリリースされた ChatGPT は GPT-3.5 をベースにしている（GPT-4 ではない）。
  • 正確には、GPT-3.5 を対話向けにファインチューニングした Web アプリケーションサービスが ChatGPT。

GPT-3 から GPT-3.5 へ ── なぜ RLHF が必要だったか

GPT-3 で高精度な文章生成は可能になったが、学習データであるインターネット上の文章には 攻撃的な表現や誤った情報も含まれる。そのまま学習すると、そうした内容を出力するモデルができてしまう。

そこで 2022年1月、この問題を解決すべく InstructGPT がリリースされた。GPT-3 をベースに RLHF（人間のフィードバックに基づいて出力を矯正する強化学習の手法）を採用したモデルである。 こうしてモデルを人間の求める適切な回答を出すように調整することを アライメント という。

GPT-3.5 も同じく RLHF を採用しており、人間の一定の価値観に基づく範囲内で動作するように設計されている点が GPT-3 との大きな違い。

マルチモーダル と オムニモーダル の違い

GPT-4o（2024年5月）の「o」は オムニ（omni＝すべての） の意味。

  • マルチモーダルモデル＝複数種類のデータを扱えるが、通常はそれぞれ個別に処理し、結果をまとめて応答する。
  • オムニモーダルモデル＝テキスト・画像・音声などを継ぎ目なく（シームレスに）統合して同時に理解・分析する。

特に音声入力への応答が速く、最短232ミリ秒・平均320ミリ秒で応答できる。 これは人が会話で返事をするスピードに非常に近い。

シラバスで挙げられている生成AIの5分類は？
テキスト生成AI／画像生成AI／音楽生成AI／音声生成AI／動画生成AI。
NLP の正式名称と意味は？
Natural Language Processing（自然言語処理）。コンピュータに人間の言葉を理解させるための技術。
LLM とは何か？
Large Language Model（大規模言語モデル）。非常に大規模なデータセットで学習された自然言語処理モデルで、代表例は ChatGPT。
ChatGPT・Claude・Gemini・Copilot の提供元は？
ChatGPT＝OpenAI／Claude＝Anthropic／Gemini＝Google（Google DeepMind）／Copilot＝Microsoft。
画像生成AI の学習で行う前処理の代表的な3手法は？
画像のリサイズ、正規化、データの水増し。
GAN はどうやって高品質な画像を作る？
生成器と識別器という2つのネットワークを競わせる（敵対的に学習させる）ことで生成品質を高める。
VAE のエンコーダとデコーダの役割は？
エンコーダは情報を圧縮して潜在ベクトル（特徴を要約した情報）にする。デコーダは潜在ベクトルから元のデータに近いものを復元する。
画像生成AI の現在の主流手法は？
ディフュージョン（拡散）モデル。ノイズを段階的に除去することで、安定学習と超高精細を実現する。GAN・VAE 中心から移行した。
自己回帰型 Transformer を組み合わせると何ができるようになった？
画像をトークン化して順次生成することで、看板の文字や細線などの細部も破綻なく表現できるようになった。
音楽生成AI が学習に使うデータの代表例は？
MIDIファイル（デジタル音楽のインターフェース規格）等の音楽データ。
音楽生成AI が「より好まれる音楽」を作れるようになる仕組みは？
人間のリスナーからのフィードバックを、新たな学習データとしてデータセットに追加していく。
音声生成AI のトレーニングに一般的に用いられる学習方法は？
教師あり学習。（強化学習・教師なし学習は誤り）
TTS とは何の略で、どんな技術？
Text-to-Speech。テキストを自然な音声へ変換する技術で、多言語・多話者・感情表現に対応する。
Eleven Labs の特徴は？
少量のサンプルから声色を再現できる高品質な TTS。感情や話速の制御、多言語合成に対応する。
動画生成AI でフレーム間の一貫性を保つために利用される技術は？
連続性のあるデータの処理に適した RNN。（訓練手法自体は GAN や VAE）
Sora の提供元・発表時期・生成できる動画の長さは？
OpenAI が2024年2月に発表。製品版は最長20秒・最大1080p（フルHD）。発表時は「最長1分の可能性」として注目された。
Veo 3 の提供元と、Sora にない特徴は？
Google DeepMind が2025年5月に発表。超高精細映像に加えて、環境音やセリフ等の音声も同時に合成できる。
ディープフェイクとは？
ディープラーニングや生成AIを利用して非常にリアルなコンテンツを作り、人を故意に騙すことを目的として使用される技術。偽情報（ディスインフォメーション）の拡散という社会問題を引き起こしている。
ChatGPT の「GPT」の各文字の意味は？
G＝Generative（生成）／P＝Pre-trained（事前学習）／T＝Transformer（Transformerモデル）。Chat は対話型。
ChatGPT の開発元と公表時期、ベースになったモデルは？
OpenAI が2022年11月に公表。GPT-3.5 を対話向けにファインチューニングした Web アプリケーションサービス。
GPT-1・GPT-2・GPT-3 の発表時期は？
GPT-1＝2018年6月／GPT-2＝2019年2月／GPT-3＝2020年5月。
GPT-1 〜 GPT-4 のパラメータ数は？
GPT-1＝約1億1,700万／GPT-2＝約15億／GPT-3＝約1,750億／GPT-3.5＝約3,550億／GPT-4＝約1兆7,600億。
GPT-2 が当初フルモデルを公開しなかった理由は？
性能が高く、誤用・悪用のリスクを理解して管理する仕組みが十分に整備されていなかったため、予防策として一部のバージョンを非公開とした。
GPT-3 で新しくできるようになったことは？
微調整（ファインチューニング）なしで、幅広い自然言語処理タスクを実行できるようになった。
RLHF の正式名称と内容は？
Reinforcement Learning from Human Feedback。人間のフィードバックに基づいて出力を矯正する強化学習の手法。
アライメント（Alignment）とは？
モデルを、人間の求める適切な回答を出すように調整すること。
InstructGPT はいつ・何をベースに作られた？
2022年1月リリース。GPT-3 をベースに RLHF を採用したモデル。
GPT-3.5 と GPT-3 の大きな違いは？
GPT-3.5 は RLHF を採用し、人間の一定の価値観に基づく範囲内で動作するように設計されている点。
ハルシネーションとは？ GPT-4 ではどうなった？
モデルが不正確あるいは誤った情報を、あたかも正確・正しい情報のように生成すること。GPT-4 でも生じるが、GPT-3.5 と比べて19〜29%程度減少した（完全解消ではない）。
GPT-4 の学習データの範囲は？
GPT-3.5 と同じく、2021年9月までの情報。
マルチモーダルとは？
テキスト・画像・音声・動画などの異なる種類のデータを一度に処理することが可能な AI 技術。モーダルは「入力方法」の意味。
GPT-4o の「o」の意味と、マルチモーダルとの違いは？
「o」はオムニ（すべての）。マルチモーダルが各データを個別に処理するのに対し、オムニモーダルはすべてを継ぎ目なく統合して同時に理解・分析する。2024年5月リリース。
Code Interpreter でできることは？
ChatGPT が Python でコードを書いて実行し、データ分析・グラフ作成・数学の計算・ファイルの読み書きを行う。2023年3月発表、7月実装。
GPTs の正式名称と機能は？
Generative Pre-trained Transformers。用途に合わせてカスタマイズした「オリジナルの ChatGPT」を作れる機能。振る舞いの設定・ファイル参照・外部API連携ができ、GPT ストアで公開・利用できる。
リーズニングモデル（GPT-o1 など）の設計思想は？
速く答えることよりも推論の質を重視し、先にじっくり考えてから応答する。数学の証明やアルゴリズム設計などに強い。

GPT-4.1（2025年4月）は開発実務向けの改良版で、超長文や大規模コードを一度に扱える。GPT-5（2025年8月）は推論力とスピードが大幅に進化し、標準版／Thinking／Pro の三種類。Thinking と Pro では誤情報が大幅に減少。
Operator と Codex はそれぞれ何をするもの？
